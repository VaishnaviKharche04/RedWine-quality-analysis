# 🍷 Wine Quality Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a red wine quality dataset using Python. The goal is to understand the characteristics of red wine and identify relationships between different chemical properties and wine quality.

## 🎯 Objectives

* Understand the structure of the dataset
* Clean and inspect the data
* Analyze the distribution of wine quality
* Study relationships between chemical properties and wine quality
* Identify correlations between variables
* Detect potential outliers
* Generate meaningful insights from the data

## 📊 Dataset

The dataset contains chemical properties of red wine along with a quality rating.

Important variables include:

* Fixed Acidity
* Volatile Acidity
* Citric Acid
* Residual Sugar
* Chlorides
* Free Sulfur Dioxide
* Total Sulfur Dioxide
* Density
* pH
* Sulphates
* Alcohol
* Quality

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 🔍 Analysis Performed

### Data Understanding

* Checked dataset shape
* Examined data types
* Checked missing values
* Checked duplicate records
* Generated descriptive statistics

### Exploratory Data Analysis

* Analyzed wine quality distribution
* Calculated average alcohol and pH
* Compared chemical properties across quality levels
* Analyzed alcohol vs. wine quality
* Analyzed volatile acidity vs. wine quality

### Correlation Analysis

A correlation analysis was performed to identify relationships between chemical properties and wine quality.

### Outlier Analysis

Boxplots and statistical methods were used to identify potential outliers in important numerical variables.

## 💡 Key Insights

The analysis identified patterns between wine quality and several chemical properties, particularly alcohol, volatile acidity, sulphates, and other chemical characteristics.

Specific findings are documented in the Jupyter Notebook based on the analysis results.
